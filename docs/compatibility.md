# Porting the Analog Comparator Contract

Hardware Definitions can describe multiplexing and event routing, but the Adapter determines which logical pairs and edges are usable together. Publish settling, hysteresis and behavior near equality at the target level. Fixed and switchable comparators fit the same level contract. Pending flags and interrupt delivery vary independently.

This repository's host simulations and shared API compile/link checks provide source-level evidence. Target timing and physical behavior require hardware validation.
